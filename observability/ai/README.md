# AI observability

Telemetry for LLM and agent workloads in aiops/, exported into the same LGTM pipeline as the boutique services.

- OpenTelemetry GenAI semantic conventions (gen_ai.* spans and metrics)
- LLM golden signals: time to first token, tokens and cost per request, error and refusal rates
- SLOs and burn-rate alerts for agent workflows
- Evaluation results from aiops/evals shown next to latency and cost
